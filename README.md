# DSA-UNIT-3-LINKED-LIST
# Student Record Management System Using Linked List

## Problem Statement
Design and implement a Student Record Management System using
a Singly Linked List to store and display student details such
as Roll Number, Name, and Marks.

## Objective
To implement a Singly Linked List for managing student records
using C++.

## Algorithm
1. Create a node containing Roll Number, Name, and Marks.
2. Allocate memory dynamically for each node.
3. Insert student records at the end of the linked list.
4. Traverse the linked list using a pointer.
5. Display all student records.

## Concepts Used
- Structure
- Pointers
- Dynamic Memory Allocation
- Singly Linked List
- Traversal

## Programming Language
C++

## Sample Input
1 Rahul 85
2 Priya 90
3 Amit 78

## Sample Output
Student Records:
Roll No: 1 Name: Rahul Marks: 85
Roll No: 2 Name: Priya Marks: 90
Roll No: 3 Name: Amit Marks: 78

## Conclusion
The program demonstrates how a Singly Linked List can be used
to store and display student records dynamically.
